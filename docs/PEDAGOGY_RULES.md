# Pedagogy Rules

These rules come from iterative listening tests.

## Rule 1 — Context is useful but not enough

A lyric can communicate the mood of a word while teaching the wrong exact meaning.

Example:
`desfase` in a romantic context could be interpreted as "a coldness between us", while the intended core meaning is "a mismatch / offset / desynchronization".

Therefore important targets need an exact semantic anchor at least once.

## Rule 2 — Do not teach like a glossary

Avoid:
- "acechar — guetter"
- "desfase — décalage"
- immediate Spanish word + French equivalent chains

They sound educational and break the musical illusion.

## Rule 3 — French must be an autonomous lyric

The French phrase should make sense on its own.

Avoid:
> Ça s'éclaircit...

Prefer:
> Après l'orage, le ciel s'éclaircit.

Avoid:
> Je t'ai pris pour acquis...

Prefer:
> Ton sourire, je l'ai pris pour acquis.

The exact equivalent is still present, but the phrase has its own image.

## Rule 4 — Do not translate the same sentence

The French passage should echo the same semantic field without merely restating the Spanish line.

This makes the bilingual writing feel intentional rather than instructional.

## Rule 5 — Spanish remains dominant

French is a precision tool, not the main teaching channel.

Default for 1 minute:
- 3–4 targets
- 1–2 French passages
- the rest in Spanish

## Rule 6 — Leave time for the listener

Rapid code-switching is cognitively noisy.

Use:
- slower vocal delivery;
- sparse lyrics;
- pauses before/after French;
- short complete lines.

## Rule 7 — Repetition changes form

Do not repeat a translation every time.

A useful sequence:
1. target in Spanish context;
2. exact French anchor elsewhere;
3. target again in Spanish;
4. later songs reuse it without French.

## Rule 8 — Favor useful ambiguity, then resolve it

The learner should often get a chance to infer meaning before the anchor arrives.

That inference is useful.

But do not leave the final meaning ambiguous.

## Rule 9 — Songs should still work as songs

If removing the learning objective leaves awkward lyrics, rewrite them.

The musical experience is not decoration; it is the delivery mechanism.
