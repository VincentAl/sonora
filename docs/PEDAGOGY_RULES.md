# Pedagogy Rules

These rules come from iterative listening tests.

## Rule 1 — The learning objective comes first

Sonora is not a bilingual mood song. Its primary purpose is to teach and reinforce precise Spanish vocabulary and expressions while still sounding like a real song.

Every French intervention must have a clear pedagogical job.

If a French sentence could be removed without reducing understanding of a target Spanish word or expression, it is probably decorative and should be removed.

## Rule 2 — Context is useful but not enough

A lyric can communicate the mood of a word while teaching the wrong exact meaning.

Example:
`desfase` in a romantic context could be interpreted as "a coldness between us", while the intended core meaning is "a mismatch / offset / desynchronization".

Therefore important targets need an exact semantic anchor at least once.

## Rule 3 — Spanish and French must share the same idea

The French anchor does not need to be a literal translation of the Spanish sentence, but it MUST clearly refer to the same action, image, situation, or semantic idea.

Bad:
> Spanish line uses `despejarse` about the sky clearing.
>
> French break talks about missing someone's smile.

Both may sound poetic, but the French line teaches nothing about the target.

Good:
> Spanish describes clouds opening and the view becoming clear.
>
> French says: "Après l'orage, le ciel s'éclaircit."

The wording differs, but the idea recurs and the exact meaning is recoverable.

## Rule 4 — Do not teach like a glossary

Avoid:
- "acechar — guetter"
- "desfase — décalage"
- immediate Spanish word + French equivalent chains

They sound educational and break the musical illusion.

## Rule 5 — French must be an autonomous lyric

The French phrase should make sense on its own.

Avoid:
> Ça s'éclaircit...

Prefer:
> Après l'orage, le ciel s'éclaircit.

Avoid:
> Je t'ai pris pour acquis...

Prefer:
> Ton sourire, je l'ai pris pour acquis.

The exact equivalent is present inside a complete natural sentence.

## Rule 6 — Do not translate mechanically

The French passage should not simply subtitle the preceding Spanish sentence word-for-word.

Instead, reuse the SAME semantic idea in a different natural sentence.

The constraint is:
- semantic overlap: mandatory;
- literal wording overlap: optional;
- exact French equivalent of the target: mandatory when that line is the anchor.

## Rule 7 — Spanish remains dominant

French is a precision tool, not the main teaching channel.

Default for about 1 minute:
- 3–4 targets;
- 1–2 French passages;
- the rest in Spanish.

## Rule 8 — Leave time for the listener

Rapid code-switching is cognitively noisy.

Use:
- slower vocal delivery;
- sparse lyrics;
- pauses before/after French;
- short complete lines.

## Rule 9 — Repetition changes form

Do not repeat a translation every time.

A useful sequence:
1. target in Spanish context;
2. semantically linked French anchor with the exact equivalent;
3. target again in Spanish;
4. later songs reuse it without French.

## Rule 10 — Favor useful ambiguity, then resolve it

The learner should often get a chance to infer meaning before the anchor arrives.

That inference is useful.

But do not leave the final meaning ambiguous.

## Rule 11 — Validate every anchor before generation

For each target, write down explicitly:

- Spanish target;
- intended French meaning;
- Spanish lyric context;
- French anchor sentence;
- shared semantic idea between the two.

Reject the lyric pack if that shared idea cannot be stated clearly in one short sentence.

## Rule 12 — Songs should still work as songs

If removing the learning objective leaves awkward lyrics, rewrite them.

But musical naturalness never justifies breaking the semantic link needed for learning.

The music is the delivery mechanism; the vocabulary learning is the product.
