# D1 dialogue — approved text experiment

This pack promotes the reviewed D1 draft into an executable experiment.

## Hypothesis

A target can repeat naturally when two people echo the same semantic idea in different concrete contexts. The repetition should feel like dialogue, not vocabulary drilling.

Targets:
- `dejar atrás`
- `añorar`

Vincent approved D1 for the next Suno test on 1 November 2026.

## Generation policy

- one Suno call only for the first test;
- expected output: two v6-mini takes;
- target duration: about 55 seconds;
- no GPT audio analysis after generation;
- human listening review by Vincent decides whether the dialogue mechanism works musically.
